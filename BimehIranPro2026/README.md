# حسابداری بیمه ایران - نسخه حرفه‌ای 2026

اپلیکیشن Android برای ثبت و مدیریت بیمه‌نامه‌های شخص ثالث و اقساط.

## امکانات
- داشبورد حرفه‌ای با آمار کل بیمه‌نامه‌ها، اقساط باز، سررسید نزدیک و وصولی
- ثبت بیمه‌نامه با شماره بیمه‌نامه، بیمه‌گذار، پلاک، مبلغ کل، نقدی، تعداد اقساط و تاریخ شروع
- محاسبه خودکار مبلغ باقی‌مانده و اقساط
- ثبت پرداخت برای هر قسط
- ویرایش و حذف بیمه‌نامه
- جست‌وجو در بیمه‌نامه‌ها
- فیلتر اقساط: باز، پرداخت‌شده و سررسید نزدیک
- گزارش مالی خلاصه
- ذخیره‌سازی واقعی روی گوشی با SQLite
- رابط کاربری فارسی و راست‌به‌چپ
- بدون نیاز به سرور برای کارکرد اصلی

## ساخت APK با GitHub
1. تمام فایل‌های این ZIP را در ریشه Repository قرار دهید.
2. فایل `.github/workflows/android.yml` از مسیر Actions اجرا می‌شود.
3. خروجی `app-debug.apk` به عنوان Artifact ذخیره می‌شود.

## نکته
این نسخه برای کارکرد آفلاین طراحی شده است تا بدون نیاز به کلید یا سرور قابل استفاده باشد. اتصال ابری می‌تواند در مرحله بعد با Supabase اضافه شود.
