# حسابداری بیمه ثالث 2026

نسخه Android برنامه مدیریت و حسابداری اقساط بیمه ثالث.

## ساخت APK در GitHub
1. محتویات این ZIP را در ریشه Repository قرار دهید؛ پوشه `.github/workflows` باید مستقیماً در ریشه Repository باشد.
2. به **Actions** بروید و workflow با نام **Build APK** را اجرا کنید.
3. پس از سبز شدن Build، همان Run را باز کنید.
4. در پایین صفحه بخش **Artifacts**، فایل **BimehIranAccounting-APK** را دانلود کنید.
5. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` داخل آن است.
