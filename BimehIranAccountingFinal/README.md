# حسابداری بیمه ثالث — نسخه 2026

اپلیکیشن اندروید فارسی برای ثبت بیمه‌نامه، پرداخت، مانده، اقساط، جستجو و گزارش مدیریتی.

## ساخت APK در GitHub
1. تمام فایل‌های این پوشه را در ریشه Repository قرار دهید.
2. Branch را `main` کنید.
3. به Actions بروید و `Build APK` را اجرا کنید.
4. پس از سبز شدن، از بخش Artifacts فایل `BimehIranAccounting-APK` را دانلود کنید.

حداقل Android 7 / API 24. اطلاعات این نسخه روی خود گوشی ذخیره می‌شود.
